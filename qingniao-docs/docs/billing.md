# 额度与计费

本页只从普通用户视角说明额度消耗，不涉及后台计费配置。

## 基本规则

- 调用模型会消耗账号额度。
- 不同模型价格可能不同。
- 输入内容和输出内容都可能产生消耗。
- 流式响应同样会统计消耗。
- 余额不足时，接口调用可能失败。

## 如何查看用量

你可以在控制台中查看调用日志、使用记录或余额信息。具体展示内容以站点当前页面为准。

## 常见消耗来源

- 输入上下文过长。
- 输出内容过长。
- 频繁重试。
- 并发任务过多。
- 使用更高价格的模型。
- 使用图像、语音等多模态能力。

## 如何避免异常消耗

- 合理设置 `max_tokens` 或对应的输出长度限制。
- 对失败重试设置最大次数。
- 为不同项目创建不同 API Key，便于定位异常来源。
- 不要把 API Key 暴露给前端或第三方。
- 对用户输入长度做限制。
- 对生产环境调用设置业务侧限流。

::: warning
如果发现额度异常消耗，请立即停用相关 API Key，并联系支持排查。
:::
