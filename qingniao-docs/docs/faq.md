# 常见问题

## Base URL 是什么？

Base URL 是接口服务的基础地址。示例：

```text
https://bluebirdapi.com/v1
```

## API Key 在哪里获取？

登录控制台后，在令牌或 API Key 管理页面创建并复制 API Key。

## 为什么返回 401？

通常是 API Key 缺失、错误、已删除或请求头格式不正确。请检查：

```http
Authorization: Bearer sk-xxxxxxxxxxxxxxxx
```

## 为什么返回 429？

说明请求频率或并发过高。请降低并发，并使用指数退避重试。

## 为什么模型不可用？

可能原因包括模型名称写错、账号无权限、模型暂时不可用或额度不足。请先调用 `/v1/models` 查看可用模型。

## 为什么响应慢？

可能与模型负载、输出长度、上下文长度、网络延迟有关。长文本建议启用 `stream=true`。

## 流式响应为什么中断？

可能是网络中断、客户端超时、代理超时或上游服务异常。请检查客户端和代理的超时配置。

## 额度扣费如何计算？

调用会消耗额度，不同模型价格可能不同，输入和输出通常都会参与统计。请在控制台查看实际用量记录。

## 是否兼容 OpenAI SDK？

青鸟 API 提供 OpenAI-Compatible 接口。你可以将 SDK 的 `baseURL` 或 `base_url` 设置为青鸟 API 的 `/v1` 地址。

## 如何切换模型？

修改请求体中的 `model` 字段即可。模型名称请以 `/v1/models` 返回为准。
