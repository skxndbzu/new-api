# 速率限制

青鸟 API 可能对单用户、单 Key、单模型或特定接口设置请求频率与并发限制。

## 可能的限制类型

- 单用户请求频率限制。
- 单 API Key 请求频率限制。
- 并发请求限制。
- 模型级限制。
- 短时间异常高频调用限制。

## 触发后的表现

通常会返回：

```http
429 Too Many Requests
```

响应体中可能包含错误信息：

```json
{
  "error": {
    "message": "Too many requests",
    "type": "rate_limit_error"
  }
}
```

## 429 处理方式

- 降低请求频率。
- 减少并发。
- 使用队列平滑请求。
- 对可重试请求使用指数退避。
- 避免多个服务实例共用同一个 Key 造成突发流量。

## 指数退避示例

```text
第 1 次重试：等待 1 秒
第 2 次重试：等待 2 秒
第 3 次重试：等待 4 秒
第 4 次重试：等待 8 秒
```

建议加入少量随机抖动，避免大量请求同时重试。

## 禁止恶意高频请求

请不要通过脚本、代理池或多账号绕过平台限制。恶意高频请求可能导致 Key、账号或相关服务被限制。
