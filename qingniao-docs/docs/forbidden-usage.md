# 禁止用途

禁止使用青鸟 API 从事违反法律法规、平台规则或侵犯他人权益的行为。

## 明确禁止

禁止使用青鸟 API 从事：

- 诈骗。
- 钓鱼。
- 赌博。
- 色情违法内容。
- 恶意代码。
- 网络攻击。
- 批量垃圾营销。
- 侵犯他人权益。
- 生成违法违规内容。
- 绕过平台限制。
- 攻击上游服务。
- 其他违反法律法规和平台规则的用途。

## 使用责任

你需要对自己的输入、输出、分发和后续使用行为负责。请确保你的业务场景符合适用法律法规、平台服务条款和用户隐私要求。

## 违规处理

平台可能对违规行为采取限制调用、冻结 Key、暂停账号、保留日志证据或配合法律程序等措施。
